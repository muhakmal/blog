selayaknya wordpress based website, website yang dibangun diatas teknologi JAMstack bisa multipurpose, seperti untuk buat website, web-cv, blog, contohnya adalah website ini sendiri muhamadakmal.id

Javascript API Markup (JAM) stack. kalau kita sudah bicara Stack dalam terminologi teknologi, kita tidak lagi berbicara spesifik tentang sistem operasi, database, web server, atau programming language tertentu pada intinya JAMstack bukan tentang teknologi speisifik, JAMstack adalah cara baru untuk buat website dan aplikasi yang menjanjikan better performance, higher security, dan better developer experience.

Actually, sudah banyak sekali website yang diimplementasi dengan teknologi JAMstack. Berikut merupakan beberapa static site generator Jekyll, Hugo, Nuxt, Next, Gatsby, atau static site generator yang lain. Website ini sendiri dibangun menggunakan Hugo.
