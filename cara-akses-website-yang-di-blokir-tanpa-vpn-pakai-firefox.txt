f:T632,<h4>Cara Akses Website yang di Blokir Tanpa VPN Pakai Firefox</h4>
<p>DNS over HTTPS adalah fitur yang relatif baru yang dirancang untuk meningkatkan privasi, keamanan, dan keandalan koneksi;</p>
<p><em>In a nutshell</em>, dengan DNS Over HTTPS ini kita bisa akses situs yang di blokir sama ISP. Tergantung kemampuan DNS Resolvernya juga sebetulnya.</p>
<h4>Cara Setting DNS Over HTTPS di Firefox</h4>
<ol>
<li>
<p>Buka <code>about:config</code> di Browser Firefox. Firefox harus diatas versi 60.x.</p>
<p><img src="https://i.loli.net/2020/05/20/psmCYMNfzTRoVIX.png" alt="dns over https firefox 1"></p>
</li>
<li>
<p>Confirm warning page yang di tampilkan</p>
<p><img src="https://i.loli.net/2020/05/20/kAnLxXP6gTbaQV1.png" alt="dns over https firefox 2"></p>
</li>
<li>
<p>Cari network.trr.mode pada config</p>
<ul>
<li>Set value pada network.trr.mode menjadi 2 untuk menjadikan DNS over HTTPS pilihan pertama dalam request payload website</li>
<li>Set value 3 untuk hanya jadikan DNS over HTTPS satu-satunya pilihan request</li>
<li>Set value 0 untuk non-aktifkan DNS Over HTTP</li>
</ul>
</li>
<li>
<p>Cari network.trr.uri dan masukkan DNS yang di provide. dari mozilla secara default menyediakan <code>https://mozilla.cloudflare-dns.com/dns-query</code> atau bisa di cek list DNS yang bisa dipakai di <a href="https://github.com/curl/curl/wiki/DNS-over-HTTPS">halaman GitHub ini</a></p>
</li>
</ol>
<p>Sumber :</p>
<ol>
<li>
<p>https://www.ghacks.net/2018/04/02/configure-dns-over-https-in-firefox/</p>
</li>
<li>
<p>https://github.com/curl/curl/wiki/DNS-over-HTTPS</p>
</li>
</ol>
